# data/test_video.mp4

Busy signalised crossing (W 42nd St, New York): pedestrian crowd on the kerb,
taxis, a coach, vans and SUVs moving through the crosswalk. Chosen because it
contains both of the classes the conflict rule needs, in the same frame.

- Source: Mixkit free stock video, clip id 4000
  https://assets.mixkit.co/videos/4000/4000-720.mp4
  (listed at https://mixkit.co/free-stock-video/crosswalk/)
- Licence: Mixkit Free Licence -- free to use, no attribution required,
  redistribution of the raw file as stock footage is not permitted.
- Properties: 1280x720, 30 fps, 401 frames (~13.4 s), 5.0 MB.

Replace this file with your own footage to run SafeCross on a different scene;
nothing else in the repo depends on this particular clip. If the new scene has
a different road layout, update `zone.polygon_norm` in `config.yaml`.
